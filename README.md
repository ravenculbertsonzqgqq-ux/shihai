# 识海 · ShiHai

> 神经元风格的无限画布思维导图 —— 集成「北极星思考决策系统」与古今中外人类智慧结晶，支持自由编辑与 AI 扩展。

## ✨ 功能

- **无限画布**：拖拽平移、滚轮缩放、网格背景随视角移动
- **神经元视觉**：发光胞体节点、突触曲线连接、脉冲信号流、跨枝「突触联想」虚线连接
- **自由编辑**：双击改字、拖拽移动、Tab/回车加节点、折叠展开、搜索跳转
- **智能布局**：左右双侧整齐树（如大脑左右半球），一键整理
- **知识集成**（400+ 节点）：
  - 北极星思考决策系统（7 大公理 / 6 大引擎 / 80+ 心智模型 / 场景手册 / 反模式库）
  - 思维方法与逻辑原理（演绎归纳溯因、第一性原理、辩证法、逆向思维、逻辑谬误……）
  - 兵书策论（孙子兵法十三篇、三十六计、武经七书、战争论、君主论、鬼谷子、资治通鉴、隆中对……）
  - 东方智慧（儒释道易、王阳明、曾国藩、菜根谭、稻盛和夫……）
  - 西方智慧（希腊哲学、斯多葛、科学方法论、物理学/数学/经济学/心理学思维……）
  - 处世经典（穷查理宝典、纳瓦尔宝典、七个习惯、黑天鹅、塔木德……）
- **AI 集成**：自定义 OpenAI 兼容 API（默认 `https://apihub.agnes-ai.com/v1` + `agnes-2.5-flash`）
  - ✨ 一键 AI 扩展节点（自动生成子要点）
  - 💬 AI 对话（自动携带选中节点上下文）
- **持久化**：自动保存到浏览器 localStorage；支持 JSON 导入 / 导出

## 🚀 本地运行

直接用浏览器打开 `index.html` 即可（无需构建）。

```bash
# 或起个静态服务
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## ⌨️ 快捷键

| 操作 | 快捷键 |
|---|---|
| 加子节点 | Tab |
| 加同级节点 | Enter |
| 编辑节点 | F2 / 双击 |
| 删除节点 | Delete |
| 适应视图 | 0 / E |
| 缩放 | + / − / 滚轮 |
| 搜索跳转 | 搜索框内 Enter |

## ⚙️ AI 配置

点右上角「⚙ AI 设置」，填入任意 OpenAI 兼容接口：

- Base URL：`https://apihub.agnes-ai.com/v1`（默认，可换）
- 模型：`agnes-2.5-flash`（默认，可换）
- Key：保存在本地浏览器 localStorage

⚠️ **安全提示**：公开部署时默认 Key 会暴露在网页中，请使用限额 Key，并定期更换。
