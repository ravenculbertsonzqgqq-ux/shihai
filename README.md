# 识海 · ShiHai v2

> 神经元风格的无限画布思维导图 —— 集成「北极星思考决策系统」与古今中外人类智慧结晶（726 节点），支持自由编辑、AI 对话操控图谱、记忆上下文索引、历史快照回滚。

## ✨ 核心功能

### 🧠 知识图谱（726 节点 · 19 条跨枝联想突触）
- **北极星思考决策系统**：7 大公理 / 6 大引擎 / 80+ 心智模型 / 场景手册 / 反模式库 / 日常协议
- **思维方法与逻辑原理**：演绎归纳溯因、第一性原理、辩证法、逆向思维、逻辑谬误、信息论、哥德尔、因果推断……
- **兵书策论**：孙子兵法十三篇、三十六计、武经七书、战争论、君主论、鬼谷子、韩非子、素书、反经、约米尼、谢林、论持久战、资治通鉴、隆中对……
- **东方智慧**：儒释道易、庄子、心经金刚经、了凡四训、王阳明、曾国藩、稻盛和夫、太极武道……
- **西方智慧**：希腊哲学、斯多葛、尼采、叔本华、笛卡尔、休谟、康德、科学方法论、物理学/数学/经济学/心理学/管理学思维……
- **处世典籍**：穷查理宝典、纳瓦尔宝典、原则、思考快与慢、影响力、乌合之众、刻意练习、心流、黑天鹅、枪炮病菌与钢铁、自私的基因、史记案例库……

### 🗣 AI 对话操控思维导图
右侧栏对话可直接指挥图谱：「给公理3加三个实战要点」「把复盘引擎和决策日志连起来」「整理布局」……
支持指令：添加/改名/备注/删除/上色/联想连接/折叠/聚焦/搜索/布局，全部可一键撤销。

### 🗂 记忆上下文索引
图谱即长期记忆：每次提问自动对 700+ 节点做检索打分，把最相关的节点（含路径与说明）注入 AI 上下文作答，并在对话中显示「已调用记忆索引」。

### 🕐 历史快照与回滚
- 每次改动自动进撤销栈（Ctrl+Z / Ctrl+Y，最多 30 步，跨会话保留）
- 📌 命名快照：保存关键状态长期保留，随时恢复
- 🕐 历史面板：完整操作清单，点击「回滚到此」精确回退

### 🎨 无限画布 · 神经元视觉
拖拽平移 / 滚轮缩放 / 发光胞体节点 / 突触脉冲流 / 跨枝联想虚线 / 左右半球整齐树布局 / 搜索 / 折叠 / 导入导出

## 🚀 本地运行

```bash
# 直接打开 index.html，或
python3 -m http.server 8080
```

## ⌨️ 快捷键

| 操作 | 快捷键 | 操作 | 快捷键 |
|---|---|---|---|
| 加子节点 | Tab | 撤销 | Ctrl+Z |
| 加同级 | Enter | 重做 | Ctrl+Y / Ctrl+Shift+Z |
| 编辑 | F2 / 双击 | 导出 | Ctrl+S |
| 删除 | Delete | 全览 | 0 / E |
| 缩放 | + / − / 滚轮 | 搜索跳转 | 搜索框 Enter |

## ⚙️ AI 配置

「⚙」里可自定义任意 OpenAI 兼容接口（默认 `https://apihub.agnes-ai.com/v1` + `agnes-2.5-flash`），配置存本地浏览器。

⚠️ 公开部署时默认 Key 会暴露在网页源码中，请使用限额 Key 并定期更换。
